Adapter запускается вместе с Cute из `main.py` как отдельный процесс.

Bridge-режим:
- фактическая логика временно подгружается из `../../адаптеррр/main.py`;
- это позволяет не дублировать тяжёлую папку, пока мало места на диске.

Безопасность токена:
- `BOT_TOKEN` основного Cute-бота не наследуется;
- adapter берёт токен только из `ADAPTER_BOT_TOKEN` или `adapter/bot_token.txt`;
- если токен для adapter не найден, запуск прерывается с ошибкой.
