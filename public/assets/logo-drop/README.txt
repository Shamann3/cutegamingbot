КУДА КЛАСТЬ НОВЫЙ ЛОГОТИП
========================

1. Положи сюда свой файл с логотипом под именем:

      logo.png

   (можно также logo.jpg / logo.webp — скрипт сам найдёт)

2. Запусти в корне проекта:

      python scripts/prepare_logo.py

3. Скрипт сам:
   - обрежет пустые края
   - сделает аккуратный PNG с прозрачностью
   - положит готовый логотип в:
        public/assets/cute-crest.png
        public/assets/cute-crest-2x.png
        public/assets/cute-crest-3x.png

4. Перезапусти ферму в Telegram (закрой Mini App полностью и открой снова).

Совет: лучше квадратный или вертикальный герб/эмблема на прозрачном фоне,
без мелкого текста (текст «CUTE / Фермерство» рисуется в интерфейсе отдельно).
