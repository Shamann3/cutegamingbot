# Мэджик — как это работает (коротко)

Одна система для **всех inline-кнопок** бота.  
Логику игр/магазина **не меняет** — только управляет кликами: скорость, защита, приоритет.

---

## Что ты нажимаешь → что происходит

```
Пользователь жмёт кнопку
        ↓
Telegram шлёт callback_query
        ↓
МЭДЖИК (middleware) перехватывает клик
        ↓
  можно? → да → запускает твой handler
              → handler может answer(..., show_alert=True)  ← алерты работают
              → если handler молчал — Мэджик гасит «часики» в finally
        ↓
  нет  → тихо гасит «часики» (без текста) → handler НЕ вызывается
```

**Пример:** создатель жмёт «Присоединиться» в бинго.  
Handler делает `answer("…не можете…", show_alert=True)` → Telegram показывает окно.  
Мэджик **не** отвечает пусто раньше — иначе алерт пропал бы (1 answer на клик).

## Из чего состоит

| Файл | Зачем |
|------|--------|
| `config.py` | **Главные настройки** — режим, лимиты, переключатели |
| `priorities.py` | Какие callback = **игры/магазин** (быстрый канал) |
| `middleware.py` | Перехват **каждого** клика по кнопке |
| `limits.py` | Антиспам, debounce, cooldown |
| `patch.py` + `audit.py` | Все `InlineKeyboard*` под Мэджик |
| `install.py` | Подключение к Dispatcher |
| `health.py` | Самолечение раз в N минут |
| `buttons.py` | Удобно создавать новые кнопки (`btn`, `markup`) |
| `core.py` | Управление на лету (`magic.set_mode`, `tune`) |

## На что влияет

### 1) Скорость («часики») + алерты
- Telegram даёт **только один** `answer` на клик.
- Мэджик **не** отвечает пусто заранее — иначе пропадут `show_alert=True`.
- Если handler сам ответил текстом/алертом — показывается он.
- Если молчал — часики гасятся в `finally` / `STUCK_ANSWER_DELAY_SEC`.
- `AUTO_ANSWER_DELAY_SEC` держи **0.0**.

### Inline-кнопки vs Inline-режим

| Что | Как защищено |
|-----|----------------|
| **Inline-кнопки** (callback) | `MagicCallbackMiddleware` — алерты, антиспам, finally |
| **Inline-режим** `@бот …` | `MagicInlineQueryMiddleware` — таймаут 4.5с, антифлуд, закрытие query |

Долгий аптайм (недели): каждые `HEALTH_INTERVAL_SEC` Мэджик чистит лимиты/кэши
(`trim`), снимает **осиротевший inflight** (зависшие handler’ы без `leave`),
при лаге делает `force_recover`. Полный `rebind` InlineKeyboard* — редко
(`HEALTH_REBIND_EVERY_N`), чтобы не подвешивать event loop каждые 5 минут.

Если кнопки «зависли» без рестарта:
```python
from bot.magic import magic
magic.force_recover()
```

Полный бот (БД, Redis, юзерботы) — отдельная инфраструктура; Мэджик гарантирует
свою цепь кнопок/inline_query, а не весь процесс ОС.

### 2) Защита (чтобы не положили бота)
Обычные кнопки (меню, помощь…):
- мало кликов в окне
- пауза между одинаковыми кликами (debounce)
- после серии блоков → **тихий** cooldown

Блок = просто погасшие часики, **без** всплывающего текста.

### 3) Приоритет игр и магазина
Если `callback_data` из `priorities.py` (или `ob_…` из onboarding):
- больше кликов разрешено
- короче debounce
- выше лимит «одновременных» обработок  

→ мины, танк, магазин, онбординг ощущаются **быстрее**, чем обычное меню.

### 4) Все кнопки под одной крышей
- Middleware на каждом `Dispatcher` (основной, Eden, support…).
- Patch/rebind: создание `InlineKeyboardButton` учитывается Мэджиком.
- Audit при старте: проверка, что файлы с кнопками связаны.

## Режимы (`config.py` → `MODE`)

| Режим | Смысл |
|--------|--------|
| `strict` | Жёстче защита |
| `balanced` | По умолчанию — баланс |
| `fast` | Мягче лимиты, быстрее для игроков |

На лету:
```python
from bot.magic import magic
magic.set_mode("strict")
magic.tune(debounce_sec=0.5)
magic.show_config()
```

## Пример по шагам

1. Игрок жмёт клетку мин → `callback_data="mineclick:3:abc"`  
2. Мэджик видит префикс `mineclick` → **priority**  
3. Debounce 0.08с, лимит выше → клик **проходит**  
4. Через ~45мс часики гаснут  
5. Работает обычный handler в `mines.py` (логика как была)

Флуд по меню (`qst:…`):
1. Много одинаковых кликов подряд  
2. Мэджик режет debounce / rate  
3. Часики гаснут **тихо**, handler не грузит бота  

---

## Что менять руками

1. **Цифры / режимы** → `bot/magic/config.py`  
2. **Новая игра в быстрый канал** → `bot/magic/priorities.py`  
   (добавь префикс callback, например `"mygame_"`)  
3. Перезапуск бота (или `magic.set_mode` / `tune` без рестарта)

---

## Чего Мэджик НЕ делает

- Не меняет правила игр, ставки, выплаты  
- Не меняет тексты кнопок и смысл `callback_data`  
- Не заменяет твои handlers — только стоит **перед** ними
