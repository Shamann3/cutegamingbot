# Дизайн: Эффекты косметики + контент + полировка UI сундуков

**Дата:** 2026-07-04
**Статус:** согласован по секциям в брейншторме, ожидает вычитки
**Продолжение:** надстройка над реализованной фичей сундуков (спеки `2026-07-04-cosmetic-lootbox-design.md`, планы backend/frontend уже влиты в master).

---

## 1. Цель

Довести фичу сундуков до «живого» состояния: рулетка показывает предметы, лента дропов живая, каталог наполнен контентом, у предметов есть окно с описанием, и — главное — **надетая косметика реально меняет игру** (фон фермы, питомец ходит по ферме, скин грядок, рамка+титул в профиле). Всё на эмодзи + CSS, без арт-ассетов.

---

## 2. Ключевые решения (из брейншторма)

| Тема | Решение |
|---|---|
| Реализация эффектов | Эмодзи + CSS (без ожидания художника) |
| Слоты с эффектом | Фон фермы, Питомец, Скин грядки, Рамка аватара + Титул — все |
| Питомец | Эмодзи-питомец **ходит** по низу экрана фермы (анимация) |
| Контент | Тематические серии, много предметов; «Весеннюю серию» убрать |
| Порядок на вкладке | Рулетка **сверху первой**, «Только что выбили» — под ней |
| Рулетка | Не пустая: реальные предметы в покое и при прокрутке |
| Лента дропов | Живая: опрос ~12 сек пока на вкладке + после своих открытий |
| Окно предмета | Тап → BottomSheet: эмодзи, название, редкость, «что это» + «что делает», кнопка Поставить/Снять (или Купить) |

## 3. Секция 1 — Полировка UI сундуков

### 3.1 Порядок и «непустая» рулетка
- На вкладке «Сундук» порядок сверху вниз: **рулетка → «🔥 Только что выбили» → счётчик/кнопки**. (Сейчас лента над рулеткой — поменять.)
- Рулетка в покое и при прокрутке наполняется реальными предметами. Источник — **пул превью**: сервер добавляет в ответ `GET /api/chests/state` поле `preview: [{emoji, rarity}, ...]` (≈12–20 предметов из активного каталога, микс редкостей). Клиент передаёт `preview` в `ChestRoulette` как `pool` (для idle-дрейфа и для филлеров при прокрутке). При открытии выпавший предмет по-прежнему встаёт под указатель (логика Task 2 фронта не меняется).

### 3.2 Живая лента
- `useChests`: пока вкладка активна — поллинг `fetchDropFeed()` каждые ~12 сек (setInterval, очищается при уходе с вкладки), плюс немедленный `refreshFeed()` после `open()`.
- Бэкенд `get_drop_feed` уже готов (rare/legendary, с именем). Изменений на сервере не нужно, кроме того что контент станет разнообразнее.

## 4. Секция 2 — Контент

### 4.1 Убрать «Весеннюю серию»
- В сид `chest_db._SEED_*` убрать серию `spring` и её предметы (или пометить `active=false`). Существующие у игроков предметы этой серии не удаляем жёстко (оставляем владение), но из каталога/дропа/альбома они уходят: проще всего — `active=false` на предметах и сете `spring`, чтобы не ломать FK владения.

### 4.2 Новое поле — описание
- `ALTER TABLE cosmetic_items ADD COLUMN IF NOT EXISTS description TEXT NOT NULL DEFAULT ''` — флавор-текст «что это». Идемпотентно, как остальные ALTER.
- «Что делает» (эффект) НЕ хранится текстом — выводится из `slot` на клиенте (единый маппинг, см. 6.3), чтобы описание эффекта всегда совпадало с реальным поведением.

### 4.3 Тематические серии (стартовый наполненный каталог)
Заводится в сид `chest_db` (идемпотентно, `ON CONFLICT DO NOTHING`). Слоты: `background | pet | plot | frame | title`. Редкости: `common | rare | legendary`. Ниже — предметы (emoji · название · slot · rarity), точные значения — в плане.

**Серия «Мифические питомцы» (pets)** — reward сета: титул «Укротитель»
- 🐉 Дракон-хранитель · pet · legendary
- 🦄 Единорог · pet · legendary
- 🐲 Виверна · pet · legendary
- 🦅 Грифон · pet · rare
- 🐺 Лунный волк · pet · rare

**Серия «Космос» (фоны + рамки)** — reward: рамка «Звёздная»
- 🌌 Фон «Галактика» · background · legendary
- 🌠 Фон «Звездопад» · background · rare
- 🪐 Рамка «Орбита» · frame · rare
- ☄️ Титул «Космонавт» · title · rare
- 🌙 Фон «Ночь» · background · common

**Серия «Времена года» (фоны)** — reward: титул «Хранитель сезонов»
- 🌅 Фон «Закат» · background · rare
- ❄️ Фон «Зима» · background · rare
- 🍂 Фон «Осень» · background · common
- 🌸 Фон «Весна» · background · common

**Серия «Ферма-люкс» (скины грядок + рамки)** — reward: титул «Фермер-магнат»
- 🟨 Скин грядки «Золотая» · plot · legendary
- 🟩 Скин грядки «Изумруд» · plot · rare
- 🟫 Скин грядки «Дубовая» · plot · common
- 🌿 Рамка «Лоза» · frame · common
- 👑 Титул «Магнат» · title · legendary

**Серия «Милашки» (питомцы + рамки)** — reward: титул «Друг зверушек»
- 🐱 Кот-садовник · pet · rare
- 🐶 Щенок · pet · common
- 🐰 Кролик · pet · common
- 🐥 Цыплёнок · pet · common
- 🎀 Рамка «Бантик» · frame · common

**Одиночные (loose, вне серий)**
- 🔥 Титул «Легенда» · title · legendary
- 💎 Рамка «Кристалл» · frame · rare
- 🌻 Скин грядки «Подсолнух» · plot · common

Итого ~30 предметов (было 9). Числа/цены осколков/веса — в плане; редкость определяет и цену осколков, и вес в пуле.

## 5. Секция 3 — Окно предмета (детали)

- Тап по предмету в коллекции (владеет или нет) → **BottomSheet** (общий компонент приложения):
  - большой эмодзи (с тем же glow-фиксом, что на карточке выигрыша);
  - название + бейдж редкости (цвет по `RARITY_ACCENT`);
  - **«Что это»** — `description` из базы (флавор);
  - **«Что делает»** — строка эффекта по слоту (маппинг 6.3), напр. «🌅 Меняет фон фермы на закатный», «🐉 Питомец будет ходить по твоей ферме»;
  - принадлежность к серии (если есть);
  - действие:
    - не куплено → «Купить за N осколков» (или «Не хватает осколков»);
    - куплено, не надето → **«Поставить»**;
    - надето → **«Снять»**.
- Экипировка/снятие — существующий `equipCosmetic(id, bool)` (один на слот). После действия — обновить коллекцию и родителя (баланс/эффекты). «Поставить» на занятый слот автоматически снимает предыдущий (уже так на бэкенде).

## 6. Секция 4 — Система эффектов (надел → реально меняется)

### 6.1 Источник правды: что надето
- Новый лёгкий эндпоинт `GET /api/cosmetics/equipped` → `{ background: {code,emoji}|null, pet: {code,emoji}|null, plot: {code,emoji}|null, frame: {code,emoji}|null, title: {code,emoji,name}|null }` — по одному активному предмету на слот из `user_cosmetics.equipped`.
- Новый хук `useEquippedCosmetics()` — грузит это, обновляется после экипировки (через общий инвалидационный сигнал/событие, напр. `window` event `cosmetics:changed`, который шлёт ChestCollection после equip/unequip).

### 6.2 Применение по слотам (эмодзи + CSS)
- **Фон** (`FarmBackground`): принимает `variant` (код фона → CSS-класс `farm-bg--{variant}`, накладывает цветовой оверлей/тон поверх сцены: закат=тёплый, ночь=тёмно-синий, зима=холодный, и т.д.). `FarmModule` берёт `equipped.background` и прокидывает `variant`.
- **Питомец**: новый компонент `FarmPet` — эмодзи надетого питомца, абсолютно спозиционирован внизу сцены фермы, CSS-анимация «ходьбы» туда-сюда (translateX + лёгкий bob, зеркалит при развороте). Рендерится в `FarmModule` когда `equipped.pet` есть.
- **Скин грядки**: `PlotCard`/грядки получают класс `plot-skin--{variant}` (цвет/рамка почвы) когда `equipped.plot` надет.
- **Рамка + титул**: `ProfileModule` (и/или шапка) — рамка вокруг аватара по `equipped.frame`, текст-титул по `equipped.title`. Витрина в профиле уже есть — расширяем её этими двумя.

### 6.3 Маппинг «слот → строка эффекта» (для окна предмета, 5)
Единый объект на клиенте, напр.:
```
background: "Меняет фон фермы"
pet:        "Питомец будет ходить по твоей ферме"
plot:       "Меняет вид грядок"
frame:      "Рамка вокруг аватара в профиле"
title:      "Титул в профиле (виден другим)"
```
Отображается вместе с эмодзи предмета.

### 6.4 Немедленность
- После «Поставить/Снять» эффект применяется без перезагрузки: `cosmetics:changed` → `useEquippedCosmetics` перечитывает → ферма/профиль перерисовываются.

## 7. Затрагиваемый код

**Backend:**
- `server/chest_db.py`: убрать `spring` из сида (active=false); наполнить сид новыми сериями/предметами; `description` в схеме и в сид-инсертах; `preview` в `get_chest_state`; новая функция `get_equipped(user_id)`.
- `server/schema.sql`: `ALTER ... ADD COLUMN description`.
- `server/app.py`: маршрут `GET /api/cosmetics/equipped` (обёрнут в try/except как остальные).

**Frontend:**
- `src/components/ChestModule.jsx`: порядок (рулетка выше ленты); передать `preview` в рулетку как pool.
- `src/hooks/useChests.js`: поллинг ленты ~12 сек.
- `src/lib/chestClient.js` + новый `src/hooks/useEquippedCosmetics.js`: загрузка надетого.
- `src/components/ChestCollection.jsx`: окно предмета (BottomSheet с описанием/эффектом/Поставить-Снять); слать `cosmetics:changed` после equip/unequip.
- `src/components/FarmModule.jsx`: читать equipped → `FarmBackground variant`, `FarmPet`, скин грядок.
- Новый `src/components/FarmPet.jsx` + CSS-анимация ходьбы.
- `src/components/FarmBackground.jsx`: проп `variant` + `farm-bg--{variant}` оверлеи в CSS.
- `src/components/PlotCard.jsx`: класс скина грядки.
- `src/components/ProfileModule.jsx`: рамка аватара + титул из equipped.
- Константы: `src/constants/chests.js` — маппинг эффектов по слоту + список кодов фонов→CSS-вариантов.

## 8. Границы / не входит

- Реальные арт-ассеты (картинки фонов, спрайты) — нет, только эмодзи+CSS. Задел: можно позже добавить `asset_url`, но не в этом раунде.
- Анимация питомца — простая CSS-ходьба (не путь по грядкам, не ИИ).
- Админ-редактирование нового контента/описаний — существующая админка (Часть 3) позже; сейчас контент через сид.
- Баланс экономики (веса/цены осколков) — стартовые значения, тонкая настройка позже.

## 9. Естественные фазы реализации

1. **Контент + бэкенд-данные** — сид (убрать spring, новые серии), `description`, `preview`, `/api/cosmetics/equipped`.
2. **Полировка UI сундуков** — порядок, непустая рулетка, живая лента, окно предмета.
3. **Система эффектов** — фон/питомец/грядки/рамка+титул читают надетое и применяются.

(Каждая фаза самостоятельно проверяема; порядок 1→2→3.)
