# Онбординг «три клика» — сценарий и тексты

Статус: обе ветки онбординга, главное меню со всеми разделами и запуск
любой из 14 одиночных игр внедрены (`bot/funcs/onboarding.py`). Экран 4
(после игры), воронка владельцев групп и лимит вывода — не сделаны.

Запуск игры реализован не рефакторингом игровых модулей, а синтетическим
сообщением: бот публикует якорь в клубе и подставляет его игре как
входящее сообщение с автором-игроком. Игровые файлы не тронуты.

## Цель

Человек, впервые открывший `@CuteGamingBot`, должен за три действия оказаться
в запущенной игре, ни разу не спросив совета у других игроков и ни разу
не набрав текстовую команду.

## Две ветки

Верхняя кнопка `/start` зависит от того, есть ли чем играть прямо сейчас.
Кошелёк считается по одному правилу: если у игрока активно бесплатное
задание, ставка идёт с его виртуального баланса, иначе — со своих кут.

```
нет кут                          есть куты (или баланс задания)
клик 1 — /start                  клик 1 — /start
клик 2 — бесплатное задание      клик 2 — выбор игры из всех одиночных
клик 3 — игра на его балансе     клик 3 — правила и «Начать играть»
```

Первая ветка ничего не стоит клубу: пока игрок не дошёл до цели задания,
настоящие куты не выдаются. Поэтому `start_balance = 0` — раздавать баланс
при регистрации не нужно, его роль выполняет задание.

Игры, которым нужен ещё один выбор (кубик — число, трейд — направление,
рулетка — цвет), показывают его вместо кнопки «Начать играть»: выбор
и есть третий клик.

## Всё остальное — на первом экране

Задания, ферма, профиль, чёрный рынок, вывод, донат, бонус, плюшки, справка
лежат в главном меню под основной кнопкой. До любого раздела — один шаг.

## Принципы, из которых всё выведено

1. **Объяснение живёт внутри выбора.** Отдельный экран с инструкцией никто
   не читает. Правила пишем в одну строку рядом с кнопкой игры — ровно там,
   где они нужны.
2. **Ни одного обещания заработка.** Продаём азарт, статус и место в топе.
   Формулировки вида «как заработать кут» из обучающего контура убираем:
   человек, которому пообещали доход, после проигрыша уходит с претензией.
3. **Ноль текстового ввода для новичка.** Команды (`башня 10`) остаются
   как быстрый способ для тех, кто уже освоился.
4. **Игры остаются в группах.** Живая лента чужих игр — это социальное
   доказательство, которого в личке нет. Бот приводит человека
   на его собственную готовую игру, а не в общий шумный чат.

## Экран 1. `/start`

### Что сейчас

`main.py:7124-7136` отправляет два сообщения: `🎩` с восемью кнопками
и `🌿` с кнопкой «Играть». Текста нет вообще. Стартовый баланс —
`start_balance = 0` (`bot/config/config.py:787`).

### Что делаем

Одно сообщение вместо двух. Три кнопки вместо восьми — остальные
переезжают в «Профиль».

**Текст:**

```
🎩 Кут — игровой клуб в Telegram.

Мини-игры на куты: башня, слоты, футбол и ещё два десятка.
Куты открывают предметы, оформление профиля и место в топе клуба.

На старте — 50 кут. Первая игра за счёт клуба.

**Кнопки:**

| ▶️ Выбрать игру | `ob_games` | главная, отдельным рядом |

Кнопки «Вывод», «Донат», «Задания», «Чёрный рынок», «О нас» с первого

## Экран 2. Выбор игры

Клик по «▶️ Выбрать игру». Показываем **три** игры, не двадцать четыре.
Подбор осознанный: одна мгновенная, одна с нарастающим напряжением,
одна с высоким шансом победы для первого опыта.

**Текст:**

```
🎲 С чего начнём?

Правило общее: ставишь куты. Выиграл — забираешь больше,
проиграл — теряешь ставку.

⚽ Футбол — один удар, гол приносит выигрыш. Самый быстрый способ
     разобраться: забивает больше половины ударов.
🗼 Башня — поднимайся по этажам, выигрыш растёт с каждым.
     Успей забрать, пока не обвалилась.
🎰 Слоты — три в ряд.

**Кнопки:**

| Текст | callback_data |

## Экран 3. Игра

Клик по игре. Дальше всё делает бот.

### Последовательность

1. Проверяем, состоит ли человек в `@CuteGamingChat`
   (`server/telegram_membership.py` уже умеет).
2. Если не состоит — экран вступления (см. ниже).
3. Проверяем баланс казны группы. Если её не хватает — берём резервную
   группу из списка или показываем экран «клуб пополняется».
4. Бот публикует в группе якорное сообщение и запускает на нём игру.
5. В личку отправляем ссылку строго на это сообщение.

### Якорное сообщение в группе

```
🗼 {Имя} начинает Башню · ставка 10 кут
```

Дальше игровой интерфейс разворачивается на этом сообщении — так же,
как сейчас он разворачивается на `message.reply()`.

### Сообщение в личке

```
✅ Игра готова.

Твоя Башня ждёт в клубе. Нажми — попадёшь прямо на неё.
```

**Кнопка:** `🗼 Открыть мою игру` → `https://t.me/CuteGamingChat/{message_id}`

Ссылка ведёт точно на сообщение пользователя, а не в общий поток.
Он видит вокруг чужие игры (то самое социальное доказательство),
но его собственная — прямо перед глазами.

### Если человек не в группе

```
🎩 Игры идут в клубе.

Там играют все — видно чужие ставки, выигрыши и топ.
Зайди, и твоя Башня запустится автоматически.
```

**Кнопки:** `Войти в клуб` → ссылка на группу; `Я вошёл` → `ob_check:tank:10`

После подтверждения вступления игра создаётся и присылается ссылка.
Состояние выбранной игры держим в памяти по `user_id`, чтобы человек
не выбирал заново.

### Если в казне группы не хватает кут

Не показываем «В группе недостаточно средств для игры» — это тупик.

```
🎩 Клуб сейчас пополняет казну.

Пока можно вырастить куты на ферме — там ставок нет,
куты начисляются за урожай.
```

**Кнопки:** `🌿 Открыть ферму` (web_app); `Попробовать снова`

## Воронка владельцев групп

Отдельный вход, который сейчас не существует, хотя механика готова.
Владелец группы пополняет казну, игроки играют, проигрыши накапливаются
в казне, владелец снимает командой «снять». Об этом сказано ровно в одном
месте — под кнопкой «Подробнее» в балансе чата, куда никто не заходит.

### Триггер

Событие «бота добавили в группу» (`bot/handlers/updatechat.py`) — сообщение
владельцу в личку.

```
🎩 Кут добавлен в твою группу.

Как это работает: ты пополняешь казну группы, участники играют.
Проигранные ставки возвращаются в казну, выигрыши уходят из неё.
При честном перевесе в пользу казны она растёт вместе с активностью,
и ты снимаешь накопленное себе командой «снять».

Казна сейчас: 0 кут. Пока она пустая, игры в группе не запускаются.
```

**Кнопки:** `Пополнить казну` · `Как это считается` · `Правила клуба`

Экран «Как это считается» должен честно показывать перевес казны
по каждой игре в процентах. Это одновременно и продажа владельцу,
и обязательство перед игроками.

## Математика: три игры чинить обязательно

Расчёт по коду. RTP — сколько возвращается игроку со 100 поставленных кут.

| Игра | Шанс победы | Множитель | RTP сейчас | Казна получает |
|---|---|---|---|---|
| Футбол | 60% (dice ∈ {3,4,5} из 5) | ×2 | **120%** | **−20** |
| Куб | 16.7% (1 из 6) | ×6 | **100%** | **0** |
| Бомбы | `HOUSE_EDGE = 0.00` | честная формула | **100%** | **0** |

Это и есть причина, по которой казна групп не растёт. Три игры
не приносят ничего, футбол вычитает.

### Футбол — `bot/config/config.py`, `multiplier_soccer`

`×2 → ×1.5`. RTP становится 90%.

Важно: нельзя чинить сужением `SOCCER_TARGET_VALUES` с `{3,4,5}` до `{4,5}`.
Telegram нарисует анимацию гола, а бот засчитает проигрыш — человек
увидит забитый мяч и потерю ставки. Это выглядит как обман, даже
если формально описано в правилах. Меняем только множитель.

Выплата `×1.5` даёт дробь на нечётных ставках. Округляем вниз
и указываем это в описании игры.

### Куб — `KUBE_MULTIPLIER`

`×6 → ×5`. RTP 83%. Вариант мягче — `×5.4` (RTP 90%), но появляется
дробь; при `×5` числа остаются целыми.

### Бомбы — `HOUSE_EDGE`

`Decimal("0.00") → Decimal("0.08")`. Формула `k = k_fair × (1 − HOUSE_EDGE)`
в `bombs.py:143-152` уже готова, меняется одна константа. RTP ≈ 92%.

### Что не трогаем в этот заход

Дартс и боулинг сейчас на RTP 67% — это перекос в другую сторону,
человек проигрывает слишком часто и уходит. Отдельным решением позже.

## Лимит вывода: обеспечение депозитом

Сейчас `canwithdrawal` по умолчанию 100 у каждого зарегистрированного
пользователя (`bot/db_create/db.py:330`). Тысяча регистраций — сто тысяч
Stars необеспеченных обязательств.

Новая формула:

```
лимит вывода = внесено Stars + K% от чистого выигрыша
```

Всё, что сверх лимита, остаётся внутри клуба: предметы, оформление,
дома, топ, ферма. Это пишется открытым текстом в правилах и на экране
вывода — не мелким шрифтом.

Значение `K` и судьбу уже выданных лимитов обсуждаем отдельно:
существующим пользователям резать лимит задним числом нельзя,
нужен грандфазеринг.

## Технические требования

### 1. Программный запуск игр

Главный пункт. Сейчас каждая игра — обработчик сообщения, жёстко
связанный с входящим `Message`:

```python
@dp.message()
async def game_filter_tank(message: Message):
    ...
    user_id = message.from_user.id
    chat_id = message.chat.id
    if message.chat.type == "private": return
```

Нужно вынести ядро в функцию:

```python
async def start_tank_game(*, user_id: int, chat_id: int, bet: int,
                          anchor: Message) -> Message
```

а обработчик оставить тонкой обёрткой. Все `message.reply(...)` внутри
заменить на работу с `anchor`.

Порядок: Футбол → Башня → Слоты. По одной игре за раз, с проверкой
после каждой. Остальные игры трогаем только когда эти три работают.

### 2. Состояние онбординга

Нужно помнить, какую игру человек выбрал до вступления в группу.
Ключ — `user_id`, TTL порядка часа.

### 3. Меню команд Telegram

`set_my_commands` у основного бота не вызывается вообще — есть только
у бота поддержки (`server/support_bot.py:131-134`). Из-за этого нет
синей кнопки «Меню». Добавить: `/start`, `/profile`, `/shop`, `/help`.

### 4. Стартовый баланс

Сейчас 0 в боте (`bot/config/config.py:787`) и 100 в вебе
(`server/config.py:421`) — кто первым зарегистрировал, тот и определил.
Свести к одному значению.
