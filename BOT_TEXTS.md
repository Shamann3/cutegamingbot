# Каталог текстов Telegram-бота (игрок-facing)

Полный список всех текстовых сообщений, которые бот(ы) отправляют игрокам.
Сгенерировано сканированием `server/*.py`. i18n отсутствует — все строки на русском, захардкожены в Python.

**Боты в проекте:**
- `server/bot.py` — основной игровой бот (групповой баланс, web-app кнопка)
- `server/support_bot.py` — бот поддержки (тикеты + апелляции банов)
- `server/admin_bot.py` — бот админки (НЕ для игроков, исключён из основного каталога, см. раздел 12)
- Прочие модули отправляют сообщения через `telegram_notify.send_telegram_message()` напрямую (HTTP-запросы к Telegram API), используя токен игрового бота или support-бота.

**Не включено в основной каталог (не игрок-facing):**
- `server/error_reporter.py` — алерты в служебный чат об ошибках сервера
- `server/audit_log.py` — лог действий админов, шлётся в служебный чат
- `server/staff_notify.py` / `server/admin_appeals.py` (`_notify_new_appeal`, `_notify_staff_coroutine`) — уведомления персоналу/владельцам через admin-бота
- `server/admin_bot.py` — сообщения адресованы администраторам, не игрокам (включено отдельным разделом ниже для полноты, т.к. технически это Telegram-бот проекта)

## Сводка по местам отправки игроку

| Канал | Функция/механизм | Файл |
|---|---|---|
| Игровой бот (групповой баланс) | `@dp.message`, `@dp.callback_query` | `server/bot.py` |
| Бот поддержки (тикеты, апелляции) | `@dp.message`, `@dp.callback_query` | `server/support_bot.py` |
| HTTP-API закрытие тикета (от админа) | `send_telegram_message` | `server/support_routes.py` |
| Решение по апелляции / ответ админа | `send_telegram_message`, `aiohttp` прямой POST | `server/admin_appeals.py` |
| Действия админа над игроком (бан/баланс/инвентарь/маркет/онбординг) | `schedule_player_telegram_dm` → `admin_player_notify.py` | `server/admin_player_notify.py`, вызывается из `server/admin_economy.py`, `server/admin_market.py`, `server/admin_users.py`, `server/db.py` |
| Продажа лота на бирже | `schedule_market_sale_telegram` | `server/user_notify.py`, вызывается из `server/db.py` |
| Массовые рассылки | `send_telegram_message` в цикле | `server/admin_broadcast.py` |
